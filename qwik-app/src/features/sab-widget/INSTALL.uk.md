# SAB Widget: інструкція запуску

## Вимоги

- Node.js
- npm
- Git

## Кроки

1. Склонувати репозиторій:

```bash
git clone <repository-url>
```

2. Перейти в папку застосунку:

```bash
cd gr8-qwik/qwik-app
```

3. Встановити залежності:

```bash
npm install
```

4. Запустити dev server:

```bash
npm run dev
```

5. Відкрити demo-сторінку в браузері:

```text
http://localhost:5173/sab-widget-demo/
```

Якщо Vite запуститься на іншому порту, використайте URL, який буде показаний у терміналі.
